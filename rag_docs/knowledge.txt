FastAPI 是一个用于构建 Python Web API 的框架，可以快速创建后端接口。

MySQL 是关系型数据库，用于保存学生信息，例如姓名、年龄、专业等。

Redis 是内存数据存储工具，可以缓存学生查询结果，减少重复访问数据库的次数。

JWT 是一种常见的令牌格式，可以用于用户身份认证。登录成功后，服务端可以签发令牌，客户端在后续请求中携带令牌。

Docker 可以将应用及其运行依赖打包到容器中，Docker Compose 可以统一管理应用、MySQL 和 Redis 等服务。

RAG 是检索增强生成技术。系统先从外部文档中检索相关内容，再把检索结果提供给大语言模型，用于生成回答。

Embedding 是将文本转换为向量的技术。系统可以通过向量相似度查找语义相关的文本。

Chunking 是把长文档拆分成较小文本块的过程，有助于控制上下文长度和提高检索的针对性。
